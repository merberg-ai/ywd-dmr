# Runtime Brand Assets

This directory contains optimized branding served by the YWD-DMR WebUI.

Expected initial files:

- `logo.webp` — medium square logo, about 384×384
- `logo-small.webp` — compact square logo, about 128×128
- `banner.webp` — wide banner, about 1024 px wide

Do not place the full-resolution source artwork here. Originals belong under `artwork/source/`.

See `docs/developers/frontend-branding.md` for the performance and responsive-use rules.
